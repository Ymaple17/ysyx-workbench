**铁律**：精确异常下，架构副作用（写 CSR、改 PC、丢弃 younger）只能发生在 **成为 head 并 commit** 之后；结构冲刷用 `RegNext`，禁止组合环。

## 1. 原理

### 1.1 精确异常视角

阶段 4 总览：异常指令 E 之前已全部 commit；E 及之后像没执行过。对本核的 **项内异常 / ecall**：

| 事件 | 何时发生 |
|------|----------|
| 写 `mepc` / `mcause` | **提交拍** `irq_commit` → `csr.io.irq` |
| 结构冲刷（ROB/RS `flush_all`） | **下一拍** `irq_commit_r` |
| 前端重定向 PC←mtvec | **下一拍**，用锁存的 `irq_mtvec_r` |
| 对外 `commit_fire` | ecall **仍提交一次**（difftest 要对齐） |

```text
不是「WBU 看见 state 就冲」——那是完成序，不是架构序。
```

### 1.2 为何必须认 ROB head

乱序后 younger 可先 WBU：

```text
ROB:  [div(older)] [ecall(younger)]
EX/WB: ecall 先完成 → 旧路径 RegNext(wbu.state) → 提前写 mepc、冲刷
随后 div 才该提交 → 与 NEMU 步数/PC 全错
```

正确模型：异常标志随指令进 ROB；仅 `cm_fire && head_state.state` 触发。

### 1.3 外部中断不在本档

外部中断属 **4g**（提交间隙采样）。本档只管 **项内** `state.state`（含 ecall、访存异常等已记入 ROB 的项）。ebreak / mret / fencei 见 4d/4e/4f。

## 2. 为何旧路径炸

| 项 | 旧（WBU→RegNext） | **4c** |
|----|-------------------|--------|
| 触发 | `RegNext(wbu.state)` | **`cm_fire && head_state.state`** |
| mepc/mcause | wb+1 拍 | **提交拍**（`csr.io.irq`） |
| 结构冲刷 | 同拍 `is_irq` | **下一拍** `irq_commit_r`（同 mispred_r） |
| ROB | `flush_idx=head_prev` 选择性 | **`flush_all`**（ecall 已提交） |
| correct_pc | 组合读 mtvec | **提交拍锁存 `irq_mtvec_r`** |

顺序核「WBU≈commit」可蒙混；3a/3d 后 WBU 路径必然在 wrong-path / younger-first 上炸。

---

## 3. 时序（铁律）

```text
拍 T0（commit ecall / 项内异常）：
  commit_fire=1；csr.irq 写 mepc/mcause
  irq_mtvec_r := mtvec
  stop_issue / idu flush（组合）
  wb_young_irq 挡 younger 写 PRF
  结构尚未 flush_all

拍 T1：
  irq_commit_r=1 → is_irq=1
  rob/rs flush_all；ifu redirect 到 irq_mtvec_r
  rename/busy 空窗口 rebuild
```

**禁止** `is_irq → wbu.is_flush → can_wb → commit_valid → irq_commit` 组合环：  
用 `head_is_exc`（不依赖 can_wb）挡 younger；结构冲刷用 RegNext。

| | ecall（4c） | fencei（4f） | mret（4e） |
|--|-------------|--------------|------------|
| T0 | commit；写 mepc/mcause | commit（可等 I$） | commit；锁存 mepc |
| T1 | flush_all；PC=mtvec | flush_all；PC=pc+4 | flush_all；PC=mepc |

## 4. 与 4b 的耦合（必看）

CSR 的 `rs1_val` **只在 enq 抓一次**。3d 允许未 ready 入队时：

```text
csrw mtvec, t0   // 若 t0 未 ready 就 enq → rs1_val=垃圾 → mtvec 写成 0
ecall            // redirect 到 0 → 饿死/ABORT
```

**修补**（`core.scala`）：

```scala
val csr_inflight = VecInit(rob.io.entries.map(e => e.valid && e.csr_write)).asUInt.orR
val csr_stall = id_is_csr && (csr_inflight || !id_s1_rdy)
```

另：`irq_mtvec_r = RegEnable(mtvec, irq_commit)`，冲刷拍用锁存值，禁止 T1 再组合读 CSR。

## 5. 接口与源码要点

### 5.1 head 异常判定（断环）

```scala
val head_is_exc = head_e.valid && Mux(head_e.done, head_e.state.state,
  wbu.valid && (wb_idx === head) && wbu.state.state)
val wb_young_irq = head_is_exc && (robAge(wb_idx, head) > 0.U)
// can_wb 加 && !wb_young_irq；head_is_exc 不经 can_wb/cm_fire
```

### 5.2 提交触发与延迟冲刷

```scala
irq_commit := cm_fire && head_state.state   // head_state：同拍 wb head 旁路
irq_commit_r = RegNext(irq_commit)
is_irq := irq_commit_r || ext_irq_flush
csr.io.irq := irq_commit || ext_irq_fire
irq_mtvec_r = RegEnable(mtvec, irq_commit || ext_irq_fire)
```

### 5.3 flush_all / correct_pc / IFU

```scala
rob.io.flush_all := is_irq || fencei_flush || mret_flush  // ecall 已提交 → 整表清
ifu.io.correct_pc := Mux(is_irq, irq_mtvec_r, Mux(mis_predict_r, …))
// 优先级：irq > mispred > fencei > mret
```

```text
ifu_in_en = is_flush || (in.valid && pc.ready)   // flush 必装 correct_pc
s_WORK+flush：有 rvalid→IDLE，否则 s_FLUSH 吞 outstanding R
```

`rob.flush_all`：清全部 valid，head/tail/count 归零。

## 6. 接线步骤

1. 确认异常 `state` 经 ID→ROB enq，wb 时写入 `entries.state`。  
2. 删「`RegNext(wbu.state)` → `is_irq`」旧路径。  
3. 加 `irq_commit` / `irq_commit_r` / `irq_mtvec_r`；`csr.io.irq` 绑提交拍。  
4. `can_wb` 加 `!wb_young_irq`（用 `head_is_exc`）。  
5. `commit_fire` 在冲刷拍禁后继（`!is_irq`）。  
6. ROB/RS 接 `flush_all`；selective `flush` 在 irq 时关掉。  
7. IFU：`correct_pc`←`irq_mtvec_r`；`ifu_in_en` 含 flush。  
8. 加 `csr_stall`（源就绪 + 在飞 CSR）。  
9. 跑单测 / cpu-tests / yield-os 冒烟。

## 7. 踩坑

| 坑 | 现象 | 处理 |
|----|------|------|
| 组合环 can_wb↔irq | 仿真挂 / X | `head_is_exc` + 延迟结构冲刷 |
| ecall 后 ROB count=16 | 满窗死锁 | `flush_all`，勿 `head_prev` |
| mtvec=0 | redirect 到 0 | CSR 等源就绪 + 锁存 mtvec |
| flush 后取指饿死 | 无指令流 | IFU 装 correct_pc / 勿卡 s_FLUSH |
| difftest 少一步 | PC/步数错 | ecall **仍** `commit_fire` 一次 |
| T1 组合读 mtvec | 偶发偏 | `RegEnable` @ commit |
| younger 在 T0 写 PRF | 架构寄存器脏 | `wb_young_irq` |
| 与 mispred 抢 mux | 错误 PC | 固定 irq 优先 |

## 附录 A：旧路径 vs 4c + 时间线

| 旧 | 4c |
|----|-----|
| `is_irq = RegNext(wbu.state.state)` | `irq_commit = cm_fire && head_state.state` |
| 同拍冲刷 / selective | `irq_commit_r` → **`flush_all`** |
| 组合读 mtvec | `irq_mtvec_r` |
| 任意 WBU 异常即动手 | **仅 head commit** |

```text
EX/WB：state 记进 ROB（同拍 head 经 head_state 旁路）
T0：写 mepc/mcause；锁存 mtvec；stop_issue；挡 younger wb

```

若 T0 就看到 `rob.flush_all`（非 mispred），冲刷提前了一拍。
