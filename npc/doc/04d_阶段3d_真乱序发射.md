## 1. 相对 3c 交付

| 项 | 3c 交付 | **3d 真乱序** |
|----|---------|----------------|
| 发射 | 最老且 ready | **ready 即可，优先最老** |
| 入队 | busy_stall | **可未 ready**，CDB 唤醒 |
| 弹出 | `issue_fire := leave_ex` | **`free_rob(d.rob_idx)`** |
| 控制流 | 无额外限制 | **禁止越过更老未决 branch/jal** |
| 访存 | mem@head | 保持 |

---

## 2. 原理

```text
add  x5, x1, x2     // 源未就绪 → 停 RS
addi x3, x0, 1      // 无关 → 可先 issue（最老卡源时）
beq  ...            // 仍在 RS 时，更年轻项不可越过（olderCtrl）
```

- **单 FU**：d_reg 同时只有一条；越过 = 最老在 RS 等源时发后条。  
- **提交**：ROB head；写回 can_wb。

---

## 3. RS 规则

```text
canIssue(i) =
  valid && src1_ready && src2_ready && memOk && !freeing
  && !olderCtrl(i)

olderCtrl(i) = ∃j. valid(j) && age(j)<age(i) && jump(j)≠NONE
memOk = !mem || rob_idx==head
issue = canIssue 中 age 最小
```

### 3.1 free_rob（铁律）

```text
leave_ex → free_rob_fire, free_rob_idx = d_bits.rob_idx
禁止 leave_ex 时 issue_fire（issue 可能是别的 ready 项）
flush_d 清 d_reg 不 free → 可重装
同拍 free 的项不可 canIssue
```

---

## 4. core 要点

```text
// 入队：去掉 busy_stall；保留 PhysLoadStall
src*_ready = !ren || busy.ready || PhysBypassable
// 派遣
rs.issue_fire := 0
rs.free_rob_* := leave_ex, d.rob_idx
// CDB
rs.cdb_* := can_wb
// mispred 窗口
fwd_ok := !mis_predict && !mis_predict_r && !irq  // 禁止 wrong-path 前递入队
// LSU/WBU：仅 irq 冲（selective 易丢已 leave 指令）
```

---

## 5. 为何必须 olderCtrl

未 ready enq 后，**未决分支仍在 RS** 时若发后条：

1. 后条可 leave → LSU → WBU → **can_wb 写 PRF**（组合 mis 尚未发生）  
2. 分支下一拍 mispred_r 冲 ROB，但 PRF 已脏  
3. 正确路径入队抓到脏值 → check 失败 / PC 错位  

olderCtrl：更老控制流指令还在 RS 时，禁止 younger issue。  
分支 leave 后 free_rob，后条才可发（此时分支已进 LSU，mis 组合拍 can_wb 挡 younger）。

## 6. 踩坑

| 坑 | 处理 |
|----|------|
| leave 弹 issue 槽 | free_rob(d.rob_idx) |
| 越过未决分支 | olderCtrl |
| LSU selective flush | 丢指令 hang → 仅 irq |
| 未完成 DIV 前递 | exu_wen 需 out.valid |
| mis 窗口前递 | fwd_ok=0 |
| 装入就弹 + flush | 指令丢 |
