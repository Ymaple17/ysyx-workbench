# 阶段 3c：RS 驱动 EX + CDB 口（历史档 · 仍最老发射）

## 学习导航
- **理论目标**：理解 RS→派遣寄存器→EX→CDB 的完整执行链，以及 CDB 唤醒、结果驻留和 mispredict 断组合环。
- **最小实现**：让 RS 真正驱动 EX/CDB，但仍只发程序序最老 ready 项；完成接口迁移后性能和顺序应与 3b 基本一致。

- **后续扩展**：3d 改成 any-ready/oldest-ready 发射并增加 CDB 唤醒，才构成真乱序执行。
- **验收方式**：涉及 RTL 时至少跑 `./mill -i mychisel.compile`、相关单测和 cpu-tests；涉及性能时再跑 `microbench mainargs=test` 并记录 before/after。

## 2. 派遣寄存器（关键 · 3d 仍沿用）

```text
RS.issue_valid/bits → d_reg（valid+bits）
d_reg → EX.in（持有）
leave_ex = d_valid && EX.out.valid && EX.out.ready
```

### 2.1 为何持有到 leave_ex

EXU **无内部指令寄存器**，`in.bits` 必须在整段执行期间稳定。  
若 `in.ready` 为真就清 d_reg，DIV 多拍会丢操作数。

### 2.2 flush_d（派遣）

```text
flush_d = irq || (mispred_r && d_young)
d_young = age(d.rob_idx) > age(flush_idx)
```

- **不**在 mispred 时无条件冲 EX（防 leave 后指令丢）  
- flush_d 清 d_reg **不**弹 RS → 项仍在，可重装  

### 2.3 3c 当时的弹出约定

```text
rs.issue_fire := leave_ex   // onlyOldest 时 = 弹出 d_reg 当前条
```

**3d 已废弃**：改为 `free_rob(d.rob_idx)`，`issue_fire := 0`（见 04d）。

### 2.4 LSU/WBU

mispred **不**冲 LSU/WBU（避免丢已 leave 指令）；wrong-path 写 PRF 靠 **can_wb**。  
访存仅 `rob_idx == rob_head` 可发（**mem@head**，阶段 5 前保守序；≠ 内存序完成）。

## 3. CDB

```text
can_wb = wb_fire && rob(idx).valid && !done && identity_match && !wb_young_mis
rs.cdb_* / prf / busy.clr 同 can_wb
```

`identity_match` 不能只比较会复用的 `rob_idx`；至少核对执行链携带的 `pc/new_phys/arch_rd`，或使用显式 generation tag。RS 项也只能在该动态指令的写回被接受后释放。

- **3c**：因 busy_stall，入队几乎总 ready，CDB 唤醒多为保险。  
- **3d**：未 ready 可入 RS，CDB 才是主唤醒路径。

## 5. mispred 时序（断组合环 · 沿用至 3d）

| 信号 | 来源 | 用途 |
|------|------|------|
| mis_predict | leave_ex 上分支 + pc_src | 停 issue/rename；can_wb 挡 younger |
| mis_predict_r | RegNext | ROB/RS/IF 结构冲刷、flush_idx |
| flush_idx | mis_rob_r / irq | 选择性清 younger |

**禁止**：`flush_idx` / `exu.is_flush` 依赖组合 `mis_predict` 再依赖 `leave_ex`（成环）。

---

## 6. 踩坑实录（3c 施工）

| 坑 | 现象 | 处理 |
|----|------|------|
| d_reg 在 ready 时清 | DIV 错结果 | hold 到 leave_ex |
| leave_ex 弹 issue 槽（any-ready） | head 丢失 hang | 3c 用 onlyOldest；3d 用 free_rob |
| 装入时弹 RS + flush_d | 指令永久丢 | flush 不弹；leave 再弹/free |
| 未完成 DIV 前递 | check 失败 | exu_wen 需 out.valid |
| 未 ready enq + 越过分支 | 错误路径污染 PRF | 3c：busy_stall；3d：olderCtrl |
| LSU is_flush 用 in.valid | 组合环 | 仅 irq 冲 LSU/WBU |
