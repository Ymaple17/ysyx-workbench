## 1. 现状瓶颈

```text
LSU：in → ar →（等 rvalid）→ out → WBU
     一次只允许 1 个 outstanding 读；miss 时整条访存链空转
```

- 数组遍历/链表遍历大量 `lw`，每拍最多 1 个 load 完成 → 访存延迟全暴露
- 8b 后每拍可发 2 条指令，但 LSU 只能吃 1 个 → 前端/执行空转

## 2. DCache 设计（教学核）

### 2.1 结构

```text
set/way：64 × 4way × 32B（与 ICache 同构）
tag 比较 + valid/dirty（可选 write-back vs write-through）
```

| 项 | 建议 |
|----|------|
| 写策略 | 写回（write-back）省带宽；或写穿（write-through）简单 |
| 分配 | miss 时读分配；store miss 可选写分配 |
| 替换 | LRU（教学实现用计数器或近似） |
| 一致性 | 单核无 snoop；fence.i 需与 I$ 交互（阶段 4f 已有） |

### 2.2 命中路径

```text
命中：ar 拍命中 → 同拍/次拍返回 rdata（1–2 拍延迟）
不命中：发起总线读（AXI ar/r），rdata 回来填 line + 返回请求者
```

**load-use 延迟目标**：命中 1–2 拍（现在就是 ~1 拍），miss 才有大延迟。

### 2.3 与 store buffer / SQ 的接法

```text
8d：store 提交写 → store buffer → 总线
9b：store buffer 里 pending 的写可先写 DCache（hit）或排队（miss）
load：先查 SQ（消歧）→ 未命中再查 DCache → 再总线
```

注意**写后读同一行**：store buffer 有同地址 → 转发（8d 已有）；DCache 命中但行是脏 → 直接给数据。

## 3. MLP：非阻塞 LSU（多 outstanding load）

### 3.1 概念

```text
MLP = 多个内存请求同时未完成
非阻塞缓存 = miss 时仍接受后续请求（不 stall）
```

现状 `s_IDLE/s_WORK` 一次一个 → 改成**多请求流水**：

### 3.2 实现选项

| 方案 | 做法 | 评价 |
|------|------|------|
| A. 多 LSB（load slot buffer） | N 个 load 槽，各带 rob_idx/addr；每拍收 1 个 rvalid | 推荐，N=2–4 |
| B. MSHR（miss status holding register） | 合并同 line miss | 进阶，省带宽 |
| C. 多 LSU 实例 | 2 个 LSU 各连总线 | 简单但 xbar 复杂 |

教学推荐 **A**：

```scala
class LSB_Entry { valid, rob_idx, addr, issued }
// 每拍：最多 1 个新 load 进 LSB；最多 1 个 rvalid 匹配出队
```

### 3.3 写回与 ROB.done

```text
每个 load 独立完成 → can_wb（各自 rob_idx）
多 CDB 或多拍仲裁：一拍拍一个 winner（8a 已有仲裁）
LSB 里的 load 被 flush → 清项（can_wb 挡 + 项失效）
```

### 3.4 与 8d SQ 交互

```text
load 进 LSB 前查 SQ（消歧，8d 组合逻辑）
若 SQ 命中 → 直接转发完成（不进 LSB，单拍）
若 SQ 部分重叠 → 等（LSB 项 pending，SQ 变化后重试）
否则 → LSB 分配 + 发 ar
```

## 5. 总线/仲裁注意

```text
xbar（5a 改过）：dmem 读写串行，写事务期间禁 AR
9b 多 outstanding 后：读可能连续多个 ar（xbar 要能连续服务 r）
方案：xbar 支持「读连续事务」或 LSB 数量×总线分时
```

**死锁检查**：store buffer 满 + LSB 满 + 总线忙 —— 提交写不能饿死（提交写有优先权，8d 已有 `!cm_writing` 互斥，9b 保持）。

## 7. 踩坑

| 坑 | 现象 | 处理 |
|----|------|------|
| LSB 项被 flush 后仍发 rvalid | 错写 PRF | can_wb 挡 + 项失效 |
| DCache miss 时新 load 串行 | MLP 白做 | LSB 非阻塞 |
| write-back 脏行被替换 | 数据丢失 | 替换前写回 |
| 写后读同地址走内存 | 读到旧值 | SQ/DCache 转发优先 |
| xbar 读连续事务卡死 | 写事务饿死 | 写优先/仲裁 |
| fence.i 后 ICache 未清 | 自修改失效 | 4f flush 保留 |
