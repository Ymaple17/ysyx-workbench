**铁律**：外部中断是 **精确中断**——像插在「下一条将提交指令之前」；不得夹在某条指令的中间效果里。

## 1. 原理：精确中断

### 1.1 和项内异常的差别

| | 项内异常 / ecall（4c） | 外部中断（4g） |
|--|----------------------|----------------|
| 来源 | 某条指令自身 | `io.interrupt` 线 |
| 认领点 | 该指令 **commit** | **提交间隙**（本拍无人 commit） |
| mepc | 异常指令 PC | **下一条将提交** PC（或 IF 当前 PC） |
| 冲刷 | 已提交，冲 younger | **全部在飞**（无人为此 trap 提交） |

### 1.2 为何必须间隙采样

| 若在…采样 | 后果 |
|-----------|------|
| 某条 `commit_fire` 同拍 | 与 CSR/异常写抢 `csr.io.irq`；mepc 含糊 |
| EXE/ID 任意拍 | 夹着未提交指令；精确中断炸 |
| store AXI 写中途 | abort 半截写 → xbar 卡死 |
| fencei/mret commit 或 flush 拍 | 双冲刷、抢 PC |

```text
trap 前：架构态 = 已提交前缀
trap 时：mepc = 本来接下来该提交的那条
trap 后：未提交全部作废，从 mtvec 重取
```

## 2. `commit_gap`：每一项为何排除

```scala
head_would_cm = commit_valid &&
  (!store || store_commit_ready) &&
  (!fencei || fencei_commit_ready)

commit_gap =
  !head_would_cm && !head_is_exc_gap &&
  !mis_predict && !mis_predict_r &&
  !fencei_flush && !mret_flush &&
  !cm_writing_gap &&
  !irq_commit_r && !ext_irq_flush

ext_irq_fire  = io.interrupt && commit_gap
ext_irq_flush = RegNext(ext_irq_fire)
```

| 排除项 | 为何 |
|--------|------|
| `!head_would_cm` | 本拍 head **会**提交 → 不是间隙 |
| `!head_is_exc_gap` | head 项内异常 → 4c 优先 |
| `!mis_predict` / `_r` | 分支纠正窗口勿插 trap |
| `!fencei_flush` / `!mret_flush` | 特殊冲刷拍勿叠 |
| `!cm_writing_gap` | store SM 忙：否则 T1 掐断 AXI |
| `!irq_commit_r` | 4c 异常冲刷拍进行中 |
| `!ext_irq_flush` | 自己的冲刷拍禁止连采 |

**刻意不依赖 `cm_fire`/`can_wb`**：用 `commit_valid`+head 类型近似，断组合环。

优先级：`项内 exception > 正常 commit > 外部中断间隙`。

## 3. 时序 / 规格

### 3.1 T0 / T1

```text
T0 ext_irq_fire=1：
  csr.irq：mepc←ext_mepc；mcause←IRQ_MEXT
  锁存 irq_mtvec_r；stop_issue；ID 组合 flush
T1 ext_irq_flush=1：
  is_irq = irq_commit_r || ext_irq_flush
  rob/rs flush_all；IF → irq_mtvec_r；挡全部 wb
```

### 3.2 mepc 空 / 非空

```scala
ext_mepc = Mux(rob.count =/= 0, head.pc, ifu.io.in.bits.next_pc)
```

| ROB | mepc | 含义 |
|-----|------|------|
| 非空 | `head.pc` | 下一条将提交 |
| 空 | IF `next_pc` | 前端当前将取 PC |

### 3.3 `IRQ_MEXT` 与 `irq_no` 加宽

```scala
val IRQ_MEXT = "h8000000b".U(32.W)  // interrupt|code=11
csr.io.irq_no := Mux(irq_commit, head_state.state_num, IRQ_MEXT)
```

旧 `irq_no` 仅 8bit 装不下 interrupt 位 → CSR 扩到 **xlen**。  
本平台无完整 PLIC/CTE；常量按手册，便于以后接 `difftest_raise_intr`。

### 3.4 与 4c 复用 `is_irq`

```scala
is_irq := irq_commit_r || ext_irq_flush
```

T1 结构冲刷同一套；差别在 T0：4g **不** `commit_fire` 任何指令，只写 CSR。

## 4. 接口与仿真默认

```text
io.interrupt → core → ext_irq_fire
```

`oood_chisel_csrc/cpu/cpu.cpp`：

```cpp
top->io_interrupt = 0; // 默认不拉；冒烟再人工拉高
```

未驱动可能为 X/1 → 无程序也 trap 进 mtvec=0。**init 强制 0** 是验收一部分。

---

## 5. 接线步骤

1. CSR：`irq_no`→xlen；`IRQ_MEXT` 常量。  
2. 算 `commit_gap`（上表）；`cm_writing_gap := store SM ≠ IDLE`。  
3. `ext_irq_fire` / `RegNext`→`ext_irq_flush`。  
4. T0：`csr.io.irq := irq_commit \|\| ext_irq_fire`；mux `irq_no`/`irq_pc`。  
5. `is_irq` 并入；锁存 `irq_mtvec_r`。  
6. `commit_fire`/`can_wb`/store·fencei pending 排除 fire/flush 拍。  
7. 仿真默认 `interrupt=0`。

---

## 6. 人工冒烟

1. `csrw mtvec, handler`；空转循环。  
2. 某拍 `top->io_interrupt=1` 保持若干拍。  
3. 观察：间隙后 `mepc/mcause`、PC→mtvec、ROB 空。  
4. 拉低；handler `mret`（4e）应能回。  
5. cpu-tests：默认 0，不回归。

store 写中途拉高时，正确实现应 **推迟**到 `!cm_writing`——冒烟宜在空转段拉。

---

## 7. 踩坑

| 坑 | 处理 |
|----|------|
| 组合环 can_wb↔flush | RegNext；采样不经 can_wb |
| 与 fencei/mret 同拍 | gap 排除其 commit/flush |
| store 写中途采样 | `!cm_writing_gap` |
| Verilator 未驱动 | init 强制 0 |
| `irq_no` 仅 8bit | 加宽到 xlen |
| 冲刷拍仍 commit | `!ext_irq_flush` 门控 |
| mepc 总用 IF PC | 非空用 `head.pc` |
| 与 4c 抢 csr.irq | gap 含 `!head_would_cm`；mux 优先 `irq_commit` |
